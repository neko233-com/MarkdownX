# UI 与手动更新验收（0.1.45）

此次调整保留现有导航、顺序、快捷键及文档主题；通过 Theme 语义 token 统一中性灰阶。参考 Vercel Geist 的背景、文字与状态层级，以及 Typora 的纸面阅读体验。现有设计系统的配色调整不引入新布局或栅格化界面概念图。

- 浅色：侧栏 `#fafafa`，纸面白色，正文 `#171717`，辅助文字 `#666666`；侧栏没有面板外框，文档仍贴齐窗口边缘。
- 深色：文档 `#0a0a0a`，侧栏 `#111111`，弹出层 `#171717`；正文 `#ededed`。带白字的蓝色按钮使用独立的稳定背景，避免自动转换导致对比不足。
- Web 阅读器与协作页面同步灰阶；保留书籍自带封面色，只调整界面强调文字的显示色，在浅深色背景上保证至少 4.5:1 对比度。键盘焦点可见，并尊重减少动态效果设置。
- 关于页的检查更新按钮始终可找到。检查中禁用重复操作，结果持久显示；自动检查关闭后仍可手动检查。失败可重试，404 表示没有正式发布，不冒充已是最新；预发布版不进入正式更新通道。
- 发现正式新版时显示版本和下载页按钮，侧栏同步提示；目的地址由校验后的版本号构造到本仓库 GitHub Releases。当前通道不下载或执行安装包。

## 验证范围

Windows 原生 GPUI 窗口以约 1280×800 检查浅深色；agent-browser 检查 Web 阅读器 1440×1000 与 390×844 的实际渲染及无横向溢出。逐项检查侧栏与纸面关系、标题/正文/辅助文字层级、按钮边界、更新控件状态、书籍强调色、手机布局。原有首屏文案和顺序保留；新增文案仅用于更新检查的真实状态与下载页入口。

`tools/harness/update_checks.py -Quiet` 使用隔离文档库与回环服务，覆盖真实异步请求、重复请求保护、自动检查关闭、失败重试、已是最新、没有正式版、无效响应及浅深色切换。正式二进制不包含该脚本入口与测试端点。

配套检查包含 Rust 工作区测试、Clippy 正式/脚本构建零警告、2000 个编辑随机种子、中英文指南往返、Python 回归、主题对比度、阅读器资源嵌入与 MSI 文件覆盖验证。macOS/Linux 本机 UI 不在此次 Windows 发布验证范围。

## 发布方式

本地 release 构建、不带 devtools，生成 MSI 和 SHA-256 校验文件；先本机升级并核对已安装文件，再手动上传 GitHub Releases。推送版本标签不会触发自动发布。MSI 为当前用户安装，未配置 Authenticode 证书，发布包明确标注未签名；WiX 的同版本升级与 per-user 目录提示属于现有安装策略。

本机 MSI 升级已成功：Windows Installer 注册版本 `0.1.45`，已安装主程序、命令行入口、协作服务器、阅读器 CSS 和 JavaScript 与本次构建逐项 SHA-256 相同。正式版使用隔离库打开 Markdown，原生「关于」页手动检查按钮可用。
