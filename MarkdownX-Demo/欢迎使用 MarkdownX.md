# 欢迎使用 MarkdownX

这个目录是 MarkdownX 的演示工作区，直接用它打开文件夹即可看到 Markdown 和 Excel 两种文档。

## 这里有

- 本页：一篇可以直接编辑的 Markdown 文档
- `销售数据.xlsx`：公式、数字格式、条件颜色和多个工作表
- `学习计划.xlsx`：完成率和状态公式
- `示例图片.png` 与 `动画.gif`：图片预览，GIF 会动
- `示例音频.wav` 与 `示例音效.mp3`：音频波形、时长和系统播放
- `示例视频.mp4`：视频缩略图和元数据，可用系统播放器播放（MDN 交互示例 CC0 素材）
- `示例模型.obj`：可拖动旋转、滚轮缩放的 3D 预览
- `扩展示例/`：一个最小可用的外部格式扩展示例

## Markdown 能做什么

标题、**加粗**、*斜体*、~~删除线~~、`行内代码`、链接和引用都能正常显示。

> 引用块适合放提示。表格、任务列表和代码块也都可以直接使用。

| 能力 | 说明 |
| --- | --- |
| Markdown | 实时编辑，保留原文排版 |
| DocxXML | MarkdownX 的结构化文档格式 |
| 电子表格 | `.xlsx` / `.xlsm` / `.xlam` 就地编辑 |
| 扩展 | 按文件后缀启动外部插件，显示只读预览 |

## 关于扩展

扩展是一个包含 `plugin.json` 的文件夹，放进设置 › 扩展里显示的扩展目录即可。扩展通过 JSON-RPC 打开自己的文件格式并返回 Markdown，MarkdownX 以只读模式显示结果。`扩展示例/` 里有清单和协议说明。
