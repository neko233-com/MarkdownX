# 演示扩展

这是 MarkdownX 外部扩展的最小清单。扩展是一个独立进程，通过标准输入的
LSP 风格 `Content-Length` JSON-RPC 通信。

## 安装

1. 构建参考扩展：`cargo build -p fdl_core --bin mdx-plugin-fixture`。
2. 把 `target/debug/mdx-plugin-fixture.exe` 复制进 `扩展示例` 文件夹。
3. 打开设置 › 扩展，点「安装扩展…」，选择整个 `扩展示例` 文件夹。
4. 安装后扩展直接出现在列表里，可以单独开关。

也可以不点安装，直接把文件夹复制到设置页底部显示的扩展目录。

## 测试

`cargo test -p fdl_core --test extensions_host` 会用同一个参考扩展覆盖发现、
握手、打开、保存、超时和非法清单；新增扩展时可以照这个测试写自己的格式用例。

之后工作区里的 `.notes` 文件会由扩展打开，MarkdownX 只读显示扩展返回的
Markdown。

## 协议

- `initialize`：请求 `{"protocolVersion":1}`；返回
  `{"protocolVersion":1,"name":"…","suffixes":[".notes"]}`，后缀必须和清单一致。
- `textDocument/open`：参数 `{"path":"…"}`；返回
  `{"format":"markdown","text":"…"}`。
- `textDocument/save`：参数 `{"path":"…","format":"markdown","text":"…"}`；
  返回 `{"ok":true}`。
- `shutdown`：结束进程前的最好一次请求。

清单字段：

```json
{
  "schema_version": 1,
  "id": "demo.notes",
  "name": "演示笔记扩展",
  "suffixes": [".notes"],
  "executable": "mdx-plugin-fixture.exe",
  "args": ["--suffixes", ".notes"]
}
```

`executable` 必须是扩展目录内的相对路径；后缀不能和内置格式或其他扩展重复。
