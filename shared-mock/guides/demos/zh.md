# 欢迎使用 MarkdownX

从这里开始记录你的想法。这是一份可以直接编辑的 Markdown 文件，修改会自动保存。

> 左侧是你的工作目录。文件保存在自己的电脑上，你随时可以重命名、移动或删除它。

## 先试一试

- [ ] 点击这一行，把它改成你的第一条笔记
- [ ] 输入 `/`，试试插入表格、代码块或待办事项
- [ ] 在左侧目录旁点击 `+`，新建一篇 Markdown 文件

## 找到你的文件

点击「我的文档」旁的 `+`，可以同时打开多个文件夹。不同图标和颜色帮助你区分目录、Markdown、图片等文件；其他类型可以从 `…` 菜单选择「使用系统应用打开」。用 `⌘ K` 搜索所有工作目录。

## 继续探索

打开「主页」，可以找到更多关于写作和交互书的指南。你也可以保留这份示例，或者把它换成自己的内容。
