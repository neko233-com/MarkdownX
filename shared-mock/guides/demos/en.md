# Welcome to MarkdownX

Start with an idea. This is a Markdown file you can edit directly; your changes are saved automatically.

> Your workspace is on the left. Your files stay on your computer, and you can rename, move, or delete them whenever you like.

## Try it out

- [ ] Click this line and turn it into your first note
- [ ] Type `/` to insert a table, code block, or to-do
- [ ] Select `+` beside the folder to create a Markdown file

## Find your files

Use `+` beside My documents to open more folders together. Distinct icons and colors make folders, Markdown, images, and other files easier to spot. Use a file's `…` menu to open other types with a system app. Press `⌘ K` to search all workspaces.
